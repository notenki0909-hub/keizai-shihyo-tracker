# 日本経済指標トラッカー

日本の主要経済指標（景気・物価・雇用・所得・対外・金利）の「いま」と推移を、
一覧で確認できる公開用 Web ツール。

- **データ源**: [統計ダッシュボード（e-Stat）API](https://dashboard.e-stat.go.jp/)（**利用登録不要**）
- **構成**: 静的サイト（Vite + Chart.js + chartjs-plugin-annotation）＋ GitHub Actions による
  平日毎日のデータチェック
- **蓄積レイヤーなし**: 毎回 API から全期間を取り直すため、速報値の改定にも自動追従。
  データの変更履歴は Git の差分で追える。
- **判断の目安つき**: 各指標に「良いとされる状態／注意が必要な状態」の解説と、
  目標値・分岐点（例：コアCPIの日銀目標2%、失業率2.5%、有効求人倍率1倍）を
  グラフ上に基準線として表示。
- **公表スケジュールに追随**: 各指標の公表機関・おおよその公表タイミングを表示。
  正確な公表日は年によって数日前後するため、固定カレンダーを追う代わりに
  平日毎日データをチェックし、変化があった時だけ自動コミット → 再公開する方式。

## 追跡している指標（11）

| カテゴリ | 指標 | 周期 | 系列コード |
|---|---|---|---|
| 景気 | 実質GDP成長率（前期比年率・季調） | 四半期 | `0705020501000060000` |
| 景気 | 景気動向指数 CI一致指数（2020基準） | 月次 | `0706010500000090010` |
| 景気 | 鉱工業生産指数（季調・2020基準） | 月次 | `0502070301000090010` |
| 景気 | 機械受注（船舶・電力除く民需・季調） | 月次 | `0701030000000010010` |
| 物価 | コアCPI（生鮮食品除く総合・前年同月比・2025基準） | 月次 | `0703010601010030010` |
| 雇用・所得 | 完全失業率（季調） | 月次 | `0301010000020020010` |
| 雇用・所得 | 有効求人倍率（季調） | 月次 | `0301020001000010010` |
| 雇用・所得 | 実質賃金指数（現金給与総額・前年同月比） | 月次 | `0302030201010030010` |
| 対外 | 貿易収支（季調） | 月次 | `1601010101000010020` |
| 対外 | 経常収支（季調） | 月次 | `1601010100000010000` |
| 金利 | 新発10年国債利回り（月末終値） | 月次 | `0702020300000010020` |

指標の追加・変更は [`scripts/indicators.config.mjs`](scripts/indicators.config.mjs) を編集する。
新しい系列コードは同ディレクトリの探索用スクリプトか、
`getIndicatorInfo?Lang=JP&SearchIndicatorWord=<キーワード>` で調べられる。

各指標には以下のフィールドがあり、編集後は `npm run fetch` で `public/data/indicators.json`
に反映してからコミットする：

| フィールド | 内容 |
|---|---|
| `description` | 指標の説明（何を測るか・公表機関・意味合い） |
| `judgment.summary` / `.goodWhen` / `.badWhen` / `.caveat` | 判断基準・良い状態/注意が必要な状態・読む上での注意点 |
| `referenceLines` | グラフに重ねる目安ライン。`{ value, label, kind }` の配列（`kind` は `target`＝目標値・分岐、`neutral`＝プラマイの分岐点、`context`＝水準の目安の3種） |
| `releaseSchedule` | 公表機関とおおよその公表タイミング（年により数日前後する目安） |

> 消費者態度指数・日銀短観・景気ウォッチャー調査は統計ダッシュボードに未収録のため対象外。

## ローカル開発

```bash
npm install
npm run fetch     # public/data/indicators.json を最新化
npm run dev       # http://localhost:5173
npm run build     # dist/ に静的ファイルを出力
npm run preview   # ビルド結果を確認
```

## 公開（GitHub Pages）

1. このディレクトリを GitHub リポジトリとして push する。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を
   **GitHub Actions** にする。
3. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) が
   - `push`（main）… ビルドして公開
   - 平日毎日 15:30 JST／手動実行 … API からデータを取り直し、変化があればコミット → 公開
   を自動で行う。

サブパス（`https://<user>.github.io/<repo>/`）配信に対応するため、
Vite の `base` は `./`（相対パス）にしてある。独自ドメインや別ホスティング
（Cloudflare Pages / Netlify 等）でもそのまま使える。

## データ更新の仕組み

`scripts/fetch-indicators.mjs` が各指標について
`getData?IndicatorCode=…&Cycle=…&RegionalRank=…&IsSeasonalAdjustment=…&RegionCode=00000`
を呼び、全期間の時系列と派生指標（前期比・前年比・最大・最小）を
`public/data/indicators.json` に書き出す。1指標でも取得できれば書き出し、
全滅時は既存ファイルを保持する。

## 出典・免責

総務省統計局ほか各府省庁の統計を、統計ダッシュボード（e-Stat）API 経由で
取得・加工。公的統計を分かりやすく表示することを目的とした非公式ツール。
