# 日本経済指標トラッカー

日本の主要経済指標（景気・物価・雇用・所得・対外・金利・為替・市場）の「いま」と推移を、
一覧で確認できる公開用 Web ツール。株価への影響度を基準に指標を選定している。

- **データ源**: [統計ダッシュボード（e-Stat）API](https://dashboard.e-stat.go.jp/)（**利用登録不要**）＋
  [JPX「投資部門別売買状況」](https://www.jpx.co.jp/markets/statistics-equities/investor-type/index.html)（Excel直接取得）＋
  [日本銀行 時系列統計データ検索サイト](https://www.stat-search.boj.or.jp/)（ドル円・日次）＋
  [FRED](https://fred.stlouisfed.org/)（日経平均株価・日次）
- **市場系3指標（ドル円・日経平均・TOPIX）は日次終値**（e-Statの月末値ではなく、可能な範囲で
  1営業日ごとに最新化）。TOPIXのみ日次データの無償入手手段が見つからず月次のまま
- **構成**: 静的サイト（Vite + Chart.js + chartjs-plugin-annotation）＋ GitHub Actions による
  平日毎日のデータチェック
- **蓄積レイヤーなし**: 毎回 API から全期間を取り直すため、速報値の改定にも自動追従。
  データの変更履歴は Git の差分で追える。
- **判断の目安つき**: 各指標に「良いとされる状態／注意が必要な状態」の解説と、
  目標値・分岐点（例：コアCPIの日銀目標2%、失業率2.5%、有効求人倍率1倍）を
  グラフ上に基準線として表示。
- **公表スケジュールに追随**: 各指標の公表機関・おおよその公表タイミングを表示。
  正確な公表日は年によって数日前後するため、固定カレンダーを追う代わりに
  平日毎日データをチェックし、変化があった時だけ自動コミット → 再公開する方式。
- **重要度★表示**: 各指標に株価・経済全体への影響度を★1〜5で表示。
- **カテゴリ別「見る順番」ガイド**: カテゴリを1つ選ぶと、その中で「①まず見る指標」
  「②次に見る指標（①を補完する視点）」を理由付きで案内する。

### JPXデータ（e-Statにない指標）について

海外投資家 売買動向のみ、e-Statに存在しないため
[`scripts/fetch-jpx-investor-type.mjs`](scripts/fetch-jpx-investor-type.mjs) が
JPXの「投資部門別売買状況」ページをスクレイピングし、公開されている `.xls` を
[SheetJS](https://sheetjs.com/)（`xlsx` パッケージ、脆弱性のあるnpm版ではなく
公式CDNの修正版 `https://cdn.sheetjs.com/...` を使用）で解析して取得している。

- 対象：東証プライム市場（2022年4月発足）の「海外投資家」区分、金額ベース、月間
- 2022年4月以降のみ収録（プライム市場発足以前は市場区分が異なるため対象外）
- **既知のリスク**：JPXは2026年10月8日公表分からファイル形式を変更予定
  （金額・株数を1ファイルに統合し、シート構成も変更）。本パーサーは変更前の
  フォーマットを前提にしており、変更後は取得ロジックの追随が必要になる。
  取得に失敗してもこの指標だけがスキップされ、他の17指標には影響しない設計。

### 日次データ（ドル円・日経平均）について

e-Statは月末値までしか提供していないため、この2指標は別の一次ソースから直接、
日次で取得している。**データ量・表示性能の兼ね合いから2016年以降のみを対象**にしている。

- **ドル円レート**：[`scripts/fetch-boj-fx-daily.mjs`](scripts/fetch-boj-fx-daily.mjs) が
  日本銀行「時系列統計データ検索サイト」の該当ページ（系列コード FM08'FXERD04）から、
  全期間が1ページにまとまったHTMLテーブルをそのままパースして取得する。
- **日経平均株価**：[`scripts/fetch-fred-series.mjs`](scripts/fetch-fred-series.mjs) が
  FRED（米セントルイス連邦準備銀行）のCSV配信（`fredgraph.csv?id=NIKKEI225`）から取得する。
  元データはNikkei Inc.の著作物で、FREDがライセンスに基づき再配布している
  （FRED該当ページに "Copyright, Nikkei Inc. Reprinted with permission." と明記）。
- **TOPIXが月次のままな理由**：JPXの日次データ（東証日報）はExcelではなく全銘柄一覧の
  巨大なPDF（数百KB〜数MB）のみで、TOPIX終値だけを抜き出すにはPDF解析の実装が必要になる
  ためコストが大きく、現時点では見送っている。BOJ・FREDにもTOPIX系列は無い。

各指標には以下のフィールドがあり、編集後は `npm run fetch` で `public/data/indicators.json`
に反映してからコミットする：

| フィールド | 内容 |
|---|---|
| `description` | 指標の説明（何を測るか・公表機関・意味合い） |
| `judgment.summary` / `.goodWhen` / `.badWhen` / `.caveat` | 判断基準・良い状態/注意が必要な状態・読む上での注意点 |
| `referenceLines` | グラフに重ねる目安ライン。`{ value, label, kind }` の配列（`kind` は `target`＝目標値・分岐、`neutral`＝プラマイの分岐点、`context`＝水準の目安の3種） |
| `movingAverage` | 詳細グラフに移動平均線を重ねる場合に設定。`{ window, label }`（`window`＝平均を取る期間の数、例：3か月移動平均なら`3`） |
| `releaseSchedule` | 公表機関とおおよその公表タイミング（年により数日前後する目安） |
| `importance` | 重要度（1〜5の整数）。カードと詳細画面に★☆で表示される |

カテゴリ別の「①まず見る／②次に見る（補完）」ガイドは `CATEGORY_GUIDES`
（同じく `indicators.config.mjs`）で定義する。各カテゴリに
`{ first: { id, reason }, second: { id, reason } }` を設定し、`id` は
`INDICATORS` の `id` と対応させる。画面ではカテゴリを1つ選択したときだけ表示される。

> 消費者態度指数・日銀短観・景気ウォッチャー調査は統計ダッシュボードに未収録のため対象外。

## ローカル開発

```bash
npm install
npm run fetch     # public/data/indicators.json を最新化
npm run dev       # http://localhost:5173
npm run build     # dist/ に静的ファイルを出力
npm run preview   # ビルド結果を確認
```

## 公開（GitHub Pages）

1. このディレクトリを GitHub リポジトリとして push する。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を
   **GitHub Actions** にする。
3. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) が
   - `push`（main）… ビルドして公開
   - 平日毎日 15:30 JST／手動実行 … API からデータを取り直し、変化があればコミット → 公開
   を自動で行う。

サブパス（`https://<user>.github.io/<repo>/`）配信に対応するため、
Vite の `base` は `./`（相対パス）にしてある。独自ドメインや別ホスティング
（Cloudflare Pages / Netlify 等）でもそのまま使える。

## データ更新の仕組み

`scripts/fetch-indicators.mjs` が各指標について
`getData?IndicatorCode=…&Cycle=…&RegionalRank=…&IsSeasonalAdjustment=…&RegionCode=00000`
を呼び、全期間の時系列と派生指標（前期比・前年比・最大・最小）を
`public/data/indicators.json` に書き出す。1指標でも取得できれば書き出し、
全滅時は既存ファイルを保持する。

## 出典・免責

総務省統計局ほか各府省庁の統計を、統計ダッシュボード（e-Stat）API 経由で
取得・加工。公的統計を分かりやすく表示することを目的とした非公式ツール。
